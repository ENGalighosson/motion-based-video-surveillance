## Motion-Based Video Surveillance

This project implements a motion-based video surveillance system using Python and OpenCV.
The system detects meaningful motion in a static video stream, removes blank frames,
and highlights moving regions using bounding boxes.

### Main Features
- Frame differencing based motion detection
- Removal of blank frames without activity
- Bounding box localization of moving objects
- Generation of an output video containing only motion frames

### Technologies
- Python
- OpenCV
- NumPy

### Notes
This project was developed as part of the Fundamentals of Computer Vision course.
